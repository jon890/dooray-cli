## ADR-035: Claude Code 스킬 수명주기와 관리형 저장소

**결정**: 스킬 설치를 `dooray skill status|install|update`로 분리하고 `setup`과 `doctor`가 같은 상태 판정·설치 모듈을 사용한다.
스킬 본문은 Node 전역 패키지 경로가 아닌 사용자 데이터 디렉터리의 버전·콘텐츠 해시별 불변 저장소에 설치하고, Claude Code 경로는 원자적으로 전환하는 심볼릭 링크로 유지한다.

**맥락**: Node 버전 관리자가 전역 npm 경로를 버전별로 분리하면 패키지 내부를 직접 가리키던 링크가 이전 CLI 버전에 고정된다.
링크 존재만 확인하는 진단으로는 오래된 스킬과 사용자 수정본을 구분할 수 없다.

**대안 기각**:

- npm `postinstall` 자동 갱신은 스크립트 비활성화·비대화형 환경·권한 정책 때문에 필수 갱신 계약으로 신뢰할 수 없다.
- 현재 npm 패키지 디렉터리 직접 링크는 같은 전역 경로에서만 자동 갱신되어 Node 버전 변경을 견디지 못한다.
- 단일 가변 복사본은 설치 중 실패와 사용자 수정 여부를 판별하기 어렵고 이전 정상본을 보존하지 못한다.

**트레이드오프**: npm 갱신 후 `dooray skill update`를 명시적으로 실행해야 한다.
대신 매니페스트와 콘텐츠 해시로 오래된 설치·수정·손상을 구분하고, 새 버전 준비와 활성 링크 전환을 분리해 부분 설치 노출을 막는다.

**적용 범위**: 첫 단계에서는 명시 명령·버전 단일 원천·기존 링크 진단을 제공하고, 다음 단계에서 관리형 저장소·매니페스트·해시 검증으로 전환한다.
자동 이전 버전 삭제와 롤백 명령은 별도 정책이 필요하므로 범위 밖이다.
