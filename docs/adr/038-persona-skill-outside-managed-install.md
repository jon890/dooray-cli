## ADR-038: `dooray-persona` 스킬을 관리형 설치 체계 밖에 둔다

**결정**: `skills/dooray-persona`를 `dooray skill` 명령의 설치 대상에 넣지 않고 npm 패키지에도 담지 않는다.
저장소를 내려받아 스킬 디렉터리를 직접 연결해 쓴다.
ADR-035의 관리형 설치는 `dooray-cli` 스킬에만 적용한다.

**맥락**: 관리형 설치기는 스킬 하나를 전제로 설치 경로와 매니페스트를 고정하고, 콘텐츠로 `SKILL.md`와 `references/`만 수집한다.
`dooray-persona`는 실행 스크립트가 본체라 지금 설치기로는 스크립트가 복사되지 않아 설치해도 동작하지 않는다.
설치기를 여러 스킬로 확장하려면 매니페스트 스키마·저장소 경로·상태 판정·테스트가 함께 움직여 스킬 본체보다 큰 변경이 된다.
또 이 워크플로우는 CLI 사용자 전원에게 필요하지 않아, 설치 기본값에 넣으면 원하지 않는 사용자에게도 깔리고 되돌릴 명령이 없다.

**대안 기각**:

- 설치기 다중 스킬 확장 — 비용이 스킬 본체를 넘고, 되돌릴 제거 명령까지 함께 만들어야 한다.
- 콘텐츠 수집 범위만 넓혀 기존 설치기에 끼워 넣기 — 스킬 이름과 설치 경로가 여전히 하나로 고정이라 두 번째 스킬을 담을 수 없다.

**트레이드오프**: npm 전역 설치만으로는 쓸 수 없고 저장소를 내려받아야 한다.
대신 설치기와 그 테스트를 건드리지 않아 기존 스킬의 설치 안정성이 그대로 유지된다.
