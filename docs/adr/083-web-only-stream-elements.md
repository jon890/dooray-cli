## ADR-083: 웹 응답에만 있는 스트림 변경 기록은 `--with-changes` 를 줄 때만 웹 모양으로 낸다

- **status**: `accepted`
- **decision-type**: `architecture`
- **areas**: `output-contract`
- **현재 규칙의 원본**: 원소 모양과 표 요약은 [스트림 변경 기록 기술 설계](../features/stream-change-records/design.md) 「인터페이스와 데이터」, 변환은 `src/api/stream/web.ts`, 출력 규약은 `CLAUDE.md` 「명령 공통 규약」 의 출력 줄. 요구사항은 [스펙](../features/stream-change-records/spec.md)
- **결정**: 웹 방식 `stream list` 는 공개 API 원소 종류에 담을 칸이 없는 웹 응답 항목(업무·일정의 시스템 기록, 위키 활동, 일정 삭제 알림, 프로젝트 카드)을 기본 출력에서 빼고, `--with-changes` 를 줄 때만 낸다.
  업무·일정의 시스템 기록은 공개 API `event` 모양에 웹의 `actions` 를 더하고 `body` 키를 뺀다. 나머지는 웹 응답의 종류와 필드를 그대로 쓴다. 표에 보일 사람 이름은 `--json` 원소에 더하지 않고 따로 찾는다.
  옵션이 없으면 뺀 건수를 stderr 로 알린다.
  [ADR-081](081-web-session-auth.md) 의 「웹 방식 `--json` 은 공개 API 응답 모양으로 바꿔 낸다」 에 대한 `stream list --with-changes` 한정 예외다. 옵션을 주지 않은 출력에는 [ADR-081](081-web-session-auth.md) 이 그대로 적용된다.
- **맥락**: [ADR-081](081-web-session-auth.md) 은 웹 방식의 `--json` 을 공개 API 응답 모양으로 바꿔 내기로 했다. 그 결과 스트림 변환이 공개 API 에 칸이 없는 항목을 버렸다.
  2026-11-16 한 계정의 2주 응답에서 버린 항목은 업무 시스템 기록 113건, 위키 활동 100건, 일정 삭제 알림 16건, 프로젝트 카드 1건, 일정 하위 기록 2건이었다. 한 시간대의 업무 활동을 세자 25건 중 9건이 빠져, 화면에 보인 활동을 CLI 로 확인할 수 없었다.
  `--json` 을 읽는 스킬과 스크립트는 공개 API 원소만 기대한다. [ADR-056](056-json-enrichment-behind-option.md) 은 기존 원소에 값을 더하는 보강을 옵션 뒤에 두기로 했다. 이 결정은 새 원소 종류를 같은 방식으로 옵션 뒤에 둔다.
- **대안 기각**:
  - **항상 낸다** — 공개 API 에 없는 원소가 기본 `--json` 에 섞여, 원소 종류로 분기하는 소비자가 모르는 원소를 만난다.
  - **표에는 항상, `--json` 에는 옵션으로** — 표와 `--json` 의 건수가 달라져 한쪽 결과로 다른 쪽을 확인할 수 없다.
  - **공통 모양(`{type: "activity", …}`) 하나로 낸다** — 웹에도 공개 API 에도 없는 모양을 CLI 가 만들어 계약으로 지켜야 한다. 웹 모양이 바뀌면 변환 규칙도 새로 정해야 한다.
  - **시스템 기록의 요약을 `body.content` 에 넣는다** — 서버에 없는 본문을 CLI 가 지어낸다(웹 세션 인증 스펙 DECISION24).
  - **`calendar`·`project` 원소에 사람 이름을 채워 낸다** — 「웹 응답 그대로」 가 깨진다. 이름은 표에만 필요하다.
- **결과**:
  - 얻는 것: 웹 방식으로 화면에 보인 활동을 빠짐없이 시각과 함께 볼 수 있다. 옵션을 주지 않은 소비자의 출력은 업무 댓글의 시각 필드 말고는 그대로다.
  - 감당할 것: 옵션을 준 출력은 웹 화면 API 의 모양을 따르므로 예고 없이 바뀔 수 있다. 웹 `project` 카드는 공개 API `project` 원소와 이름이 같지만 모양이 다를 수 있다. 표의 이름 조회가 실패하면 이름 대신 멤버 id 가 보인다.
- **확인 방법**: `src/api/stream/web.test.ts` 가 옵션 유무에 따른 원소 분리와 원본 필드 보존을, `src/commands/stream/list.test.ts` 가 건수 안내와 공개 API 방식 경고를 본다.
