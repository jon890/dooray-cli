# 웹 방식 post 명령의 인수 검증 계획

## 준비와 실행 범위

PR1이 머지되고 이 영역의 로컬 검사와 코디네이터의 독립 검토가 끝난 뒤 실행한다.
SESSION은 로그인된 ego 브라우저의 CDP Network.getCookies로만 읽고 임시 HOME의 설정 입력에 stdin으로 전달한다.
macOS에서는 그 설정 경로의 키체인 항목을 사용한다.
실제 사용자 설정은 수정하지 않고 비밀값·호스트·실명·실제 ID는 출력하거나 저장하지 않는다.
요청은 직렬로 보내며 초당 한 번을 넘기지 않는다.
401·429면 즉시 멈추고 코디네이터에게 묻는다.

쓰기는 지정된 `<project>`에서 자신만 담당자로 넣고 참조자를 비운 임시 업무로 한정한다.
제목은 `[cli-web-probe]`로 시작한다.
기존 업무의 제목·본문·참여자를 바꾸지 않는다.
실패로 중단해도 만든 업무·댓글·첨부를 추적해 삭제한다.
SESSION 입력과 CLI 출력은 프로세스 안에서 처리하고 검증 결과의 참·거짓과 필드 이름만 기록한다.
실제 응답 파일을 고정 fixture로 사용하지 않는다.

## 정리와 증거

임시 업무·댓글·첨부를 삭제한 뒤 제목 접두사 조회 결과가 비었는지 확인한다.
작업 공간을 finish하고 임시 HOME을 지운다.
설정 경로 해시의 키체인 항목을 지운 뒤 find-generic-password 종료 코드 44를 확인한다.
PR 본문에 실행 명령 목록·필드 비교 결과·미지원 옵션·정리 결과를 넣는다.
307은 실측이 없으면 테스트 증거라고 명시한다.
API 복구 뒤 API 키 방식과 실제 응답을 비교하는 일은 스펙에 따른 후속 확인이며 이번 완료 조건으로 삼지 않는다.
