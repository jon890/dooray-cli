# 작업 계획의 장문 줄 누락

## 관찰

문서 재검증에서 두 단계 문서에 200자를 넘는 줄 일곱 개가 남아 있음을 확인했다.

## 원인

첫 문서 보완은 ADR 지적에 집중해 같은 누적 차이에 포함된 신규 작업 문서 전체의 줄 길이를 확인하지 않았다.

## 영향

계획의 의미는 정확하지만 사람이 읽고 검토하기 어려우며 저장소 마크다운 가독성 규칙을 충족하지 않는다.

## 대응

장문 문장을 의미 단위로 나누고 긴 파일별 작업 설명은 중첩 목록으로 바꾼다.

## 검증

코드 블록을 제외한 두 단계 문서에서 200자를 넘는 줄이 없음을 확인했다.

## 배운 점

문서 수정 판정은 지적된 파일만이 아니라 누적 변경의 같은 검증 축 전체를 다시 검사해야 한다.

## 후속

저장소 전용 문서 검증자의 최종 판정을 받는다.
