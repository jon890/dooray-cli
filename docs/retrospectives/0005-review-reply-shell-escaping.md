# 리뷰 답글의 셸 명령 치환 방지

## 관찰

리뷰 답글 본문을 `gh api` 명령 인자에 직접 넣자 마크다운 백틱이 셸 명령 치환으로 해석됐다.

## 원인

구조화된 도구 호출 안에서 문자열을 JSON으로 감싸면 셸에서도 안전하다고 잘못 가정했다.
실제 명령은 다시 셸을 통과하므로 백틱이 실행됐다.

## 영향

로컬 셸에서 존재하지 않는 명령 실행 오류가 발생했고 네트워크 요청도 실패했다.
GitHub에는 답글이 게시되지 않았으며 저장소 파일은 변경되지 않았다.

## 대응

답글 본문을 임시 파일로 만들고 `gh api -F body=@<file>`로 전달하도록 바꿨다.

## 검증

세 인라인 댓글에 파일 기반 답글을 등록하고 반환된 댓글 ID를 확인한다.

## 배운 점

마크다운을 포함한 외부 게시 본문은 셸 인자에 직접 보간하지 않고 항상 본문 파일로 전달한다.

## 후속

기존 전역 명령 이스케이프 규칙에 이미 포함된 문제이므로 별도 지침으로 승격하지 않는다.
