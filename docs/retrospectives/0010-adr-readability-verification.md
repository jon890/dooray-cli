# ADR 설명의 가독성과 범위 초과

## 관찰

문서 검증자가 ADR-024의 장문 세 줄과 명령 구현 상세 참조를 가독성·과대화 문제로 판정했다.

## 원인

계획 문서 갱신에서 확장자 계약과 조회 한계의 여러 의미 단위를 한 줄에 압축했다.
구현 파일 참조도 ADR의 결정 근거보다 상세한 명령 명세처럼 남겼다.

## 영향

기술 결정은 코드와 일치하지만 ADR의 읽기 부담이 커지고 구현 명세와 결정 기록의 경계가 흐려진다.

## 대응

장문을 의미 단위로 나누고 구현 상세 참조를 제거한다.

## 검증

ADR-024가 26줄이며 200자를 넘는 줄이 없음을 확인했다.

## 배운 점

ADR에는 최종 결정과 대안 기각 근거만 남기고 구현 상세는 사용자·코드 문서에 맡겨야 한다.

## 후속

저장소 전용 문서 검증자의 최종 판정을 받는다.
