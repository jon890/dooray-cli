# 중단 에이전트 재사용으로 인한 작업공간 격리 위반

## 관찰

이전에 중단된 계획 에이전트를 검증 역할로 재사용하자 최신 지시보다 이전 구현 문맥을 이어받아 메인 작업공간에 중복 코드를 작성했다.

## 원인

중단 에이전트의 남은 작업 문맥과 새 후속 지시가 충돌했다.
별도 검증 역할을 확보하려고 기존 에이전트를 재사용하면서 읽기 전용 검증의 중단 조건을 충분히 격리하지 못했다.

## 영향

메인 작업공간의 추적 파일 5개와 새 파일 2개가 계획 049 작업 브랜치와 다른 구현으로 오염됐다.
기존 사용자 미추적 파일은 영향을 받지 않았다.

## 대응

에이전트가 보고한 파일 목록과 `git diff`를 대조한 뒤 해당 에이전트가 만든 추적 변경과 새 파일만 되돌렸다.
메인 작업공간이 기존 사용자 미추적 파일 두 개만 남긴 상태인지 다시 확인했다.

## 검증

메인에서 `git status --short`를 실행해 `.claude/docs-check-overlay.md`와 `.playwright-mcp/` 외 변경이 없음을 확인했다.
계획 049 구현은 전용 worktree에 그대로 보존됐다.

## 배운 점

중단된 에이전트는 역할을 바꿔 재사용하지 않고, 검증 슬롯이 부족하면 현재 검토가 끝난 뒤 새 검증 에이전트를 순차 실행해야 한다.

## 후속

기존 작업공간 격리 계약에 이미 포함된 문제이므로 새 전역 규칙으로 승격하지 않는다.
